# 알뜰픽 배포 전용 브랜치

기존 프로젝트의 main 브랜치와 별개로 운영하는 Render 무료 테스트 사이트입니다.

## 시작

`npm start`

API 키가 없으면 데모 상품만 표시합니다. Render 환경변수 `ADPICK_API_KEY`로 비밀키를 등록하면 실데이터를 서버에서 가져옵니다.

API 응답은 저장하지 않으며, 응답에 포함된 제휴 링크를 그대로 사용합니다. 배포 전 실제 제휴 광고 게재 조건을 확인하세요.

**주의**: 이 브랜치는 임시로 분리한 배포용이며 장기 운영에는 독립 저장소로 이전하는 것을 권장합니다.
