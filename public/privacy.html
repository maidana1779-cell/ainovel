개인정보 처리 안내

알뜰픽은 회원가입이나 자체 결제 기능을 운영하지 않습니다. 상품 탐색 과정에서 처리될 수 있는 정보와 외부 서비스 이용 범위를 공개합니다.

1. 서비스에서 다루는 정보

현재 알뜰픽에서는 회원가입, 주문서 작성, 배송지 입력, 별도 상담 신청 기능을 제공하지 않습니다. 상품 검색어와 API 요청 정보는 화면에 검색 결과를 제공하기 위해 전송될 수 있습니다.

현재 구현된 서버의 운영 통계는 검색 횟수, 사전에 정한 일부 검색어 범주, 상품 클릭 횟수와 판매처 범주 등 집계 수준의 수치를 메모리에 저장하며, 개별 방문자를 식별하기 위한 쿠키·기기 ID나 검색어 원문을 분석 기록으로 저장하도록 설계하지 않았습니다.

다만 실제 웹 통신에는 IP 주소, 접속 시각, 브라우저·요청 정보 등이 수반되며, 호스팅·CDN 제공사의 보안 및 장애 대응 로그에 기록될 수 있습니다.

2. 브라우저 저장소와 이용 목적

최근 정상적으로 불러온 상품 목록을 재표시하기 위해 브라우저의 sessionStorage에 상품 제목, 가격, 제휴 이동 링크 등을 약 90초 동안 임시 보관할 수 있습니다. 이는 상품 로딩 화면 개선을 위한 것으로, 회원 식별을 목적으로 하지 않습니다.

브라우저 탭이나 세션이 종료되면 관련 저장소는 브라우저 정책에 따라 정리되며, 설정에서 직접 삭제할 수도 있습니다. 운영 통계는 Render 무료 서버의 메모리에 보관되어 서버가 다시 시작되면 초기화됩니다.

3. 외부 서비스 및 링크

서비스 표시와 상품 탐색에 다음 외부 서비스가 사용될 수 있습니다.

  • Render: 웹페이지 및 백업 상품 API 제공
  • Cloudflare Workers: 상품 API 응답 및 짧은 기간의 공개 상품 목록 캐시
  • 애드픽 BIZ: 제휴 상품 정보와 추적 링크 제공
  • 토스쇼핑: 운영자가 등록한 쉐어링크 상품의 외부 이동
  • jsDelivr: 웹폰트 파일 제공

외부 상품 링크를 열면 각 판매처 또는 제휴사의 개인정보 처리방침과 쿠키 정책이 별도로 적용됩니다. 알뜰픽이 해당 외부 서비스의 처리 행위를 직접 통제하는 것은 아닙니다.

4. 보유·이용 기간 및 보호 조치

최근 상품 표시용 브라우저 저장 값은 저장 시각을 기준으로 90초를 초과하면 재사용하지 않습니다. 상품 API의 공개 응답은 구성에 따라 수분간 캐시될 수 있으며, 개인 구매내역을 포함하지 않습니다.

시스템 접속기록 등 호스팅 사업자 자체의 로그 처리 기간은 해당 제공사의 정책에 따릅니다. 알뜰픽은 운영상 필요한 API 키를 공개 페이지나 저장소에 직접 노출하지 않도록 관리합니다.
